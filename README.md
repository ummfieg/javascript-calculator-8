# javascript-calculator-precourse

### [구현 기능 목록]

**🧩 덧셈 기능(계산)**

1. 문자열 입력받기
2. 기본 구분자(:,), 커스텀 구분자('//\n')를 구분자로 분리
3. 커스텀 구분자가 '-'일 경우 커스텀 구분자로 설정
4. 숫자로 변환 후 합계 계산

**❗️ 예외 처리(검증)**

1. 구분자 형식이 아닐경우
2. 숫자가 아닌 값 포함("1,2:a")
3. 음수를 포함한 경우("-3,1,1")
4. 빈 문자열을 입력한 경우 '0'반환

---

### [구현 로직]

1. 사용자 입력값을 받음
2. 빈 문자열 검증 후 빈 문자열일 경우 '0' 반환
3. 입력 문자열 파싱, 검증 후 반환된 값을 계산 함수에 전달
4. 반환된 값으로 계산 함수 실행
